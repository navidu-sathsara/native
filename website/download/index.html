Download the installer for your platform above and run it. On Windows that's the Setup exe, on Linux mark the AppImage executable (or install the .deb), on macOS drag the app from the DMG into Applications.

Yes — Native is free and MIT-licensed open source. You only need to own Minecraft: Java Edition to play online.

Windows 10 or 11, any mainstream Linux distribution (glibc 2.33+), or macOS 13+. Both x64 and ARM64 are supported everywhere. Java is downloaded automatically when a version needs it.

Native checks quietly in the background, downloads while you play and applies on the next restart. Windows uses delta packages so updates stay small; AppImage swaps atomically; .deb installs update through your package manager.

To play online, yes — sign-in works out of the box with no setup, and tokens are encrypted with your OS keychain. Offline profiles are available for singleplayer and LAN.

Native is code-signed through SignPath's free open-source program, so the certificate is issued to SignPath Foundation and verified against our public repository. Same binaries, independent verification.

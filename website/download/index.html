Questions? We’ve got answers.

Most Windows PCs use the x64 Setup executable. Most modern Macs use the Apple Silicon DMG. Linux users who want Native to update itself should choose AppImage; Debian packages update through the system package manager.

Minecraft is downloaded from Mojang after you create an instance and is not redistributed with Native. Java is resolved separately: Native uses a compatible installed runtime or asks before downloading a managed Temurin runtime.

Windows signing is enabled when the SignPath Foundation release credentials are available. macOS signing and notarization depend on Apple credentials. Release notes identify the current build state, and the public source remains available for independent builds.

Native checks its public GitHub Releases feed. Windows and macOS builds prefer block-level differential patches; AppImage updates atomically. Native will not silently replace a failed patch with a full installer download.

Yes. The full launcher is available under the MIT License on GitHub, including the build, test, packaging, release metadata, and update verification scripts.
